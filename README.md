# GOLDJACK

## Instalación

Para correr la aplicación crea un entorno virtual utilizando el siguiente comando:
```bash
python -m venv env
```
Luego instala todas las dependecias especificadas en el archivo *requirements.txt*:
```bash
pip install -r requirements.txt
```

Para ejecutarlo utiliza el siguiente comando:
```bash
streamlit run demo_application/main.py
```
Las imágenes de prueba utilizadas se encuentran en la carpeta [data/blackjack_test_images](./data/blackjack_test_images).
